# Stuck-Loop

Probleme nicht abbrechen. Maximal drei Umlaeufe, dann Doelf.

1. Engine A: Fehler + ein Fix.
2. Engine B: Test wiederholen oder Gegenvorschlag.
3. Ergebnis in docs/COMPARE.md oder docs/reviews/.
4. Bleibt unklar: eine Frage an Doelf, kein neuer Feature-Ast.

Beispiel dieser Runde: MuJoCo-Install 502 — Retry, Messung nachgeholt, COMPARE geschrieben.
